# iOS 简约风 UI 重新设计与重构 (App UI Redesign)

## Goal

基于 iOS 简约与现代设计语言（参考 Apple Reminders / Things 3 质感），对 Nextdo 移动端及桌面端界面进行系统性视觉与交互重构：
1. 重塑 Design Tokens 色彩与材质层级（Grouped Background、纯底色卡片反差、无硬边框、细分割线、现代化 Accent 色）；
2. 调整信息架构与 Tab 布局（收件箱排为第一 Tab，初次打开页面提供自动聚焦的极速捕获弹窗）；
3. 彻底重构按钮体系与间距密度（核心行动主次分明、全宽/醒目开始按钮、次级操作栏分流、44pt+ 触控热区与呼吸感留白）。

保持全部既有数据契约、GTD 核心引擎规则与 PowerSync 响应式查询不变。

---

## Background & Current State

- **现状问题**：
  - **色彩与材质单调**：目前大量使用 `bg-canvas (#F7F6F2)` + `bg-surface (#FFFFFF)` 搭配显眼的硬边框 `border (#E4E2DB)`，视觉灰蒙、像线框原型。
  - **Tab 顺序不合理**：当前 Tab 顺序为 `现在 / 收件箱 / 项目 / 回顾`，用户进入 GTD 系统首先需要倾倒想法（Capture），收件箱应当是首要落地点。
  - **按钮严重拥挤**：【现在】执行屏中，`[开始]`、`[换一个]`、`[稍后]` 三个性质完全不同的按钮等宽紧挤在一行，容易误触且缺少核心行动的感官驱动；场景/时间 Chips 堆叠厚重。
  - **缺乏即时捕获引导**：开屏没有直接的输入触发，捕获阻力不够低。

## Requirements

### R1. 色彩与材质系统升级 (Design Tokens)
- **色彩分层**：
  - 画布底色 `canvas`：改为 iOS Grouped 背景色（浅色 `#F2F2F7`，深色 `#000000` 纯黑沉浸）。
  - 卡片表面 `surface`：改为 iOS Inset Card（浅色 `#FFFFFF`，深色 `#1C1C1E`），去除 1px 生硬灰色边框，依赖底色对比与轻阴影分层。
  - 分割线 `separator`：引入低不透明度细分割线（浅色 `rgba(60,60,67,0.12)`，深色 `rgba(235,235,245,0.15)`）。
  - 强调色 `accent`：升级为清爽精致的 iOS 风格森林墨绿（浅色 `#1B5E3A`，深色 `#4CD964` / `#5CA985`），并优化标签与状态高亮。
- **圆角与间距**：标准卡片采用 `rounded-2xl` (14~16pt)，按钮 `rounded-xl` (10~12pt)，整体组件遵循 8pt 网格与充分内边距。

### R2. Tab 栏与页面导航架构重排
- **Tab 顺序**：调整为 `收件箱 (Inbox) | 现在 (Now) | 项目 (Projects) | 回顾 (Review)`。
- **默认落地页**：首选收件箱为 Tab 0。
- **Tab 栏视觉**：采用 iOS 磨砂/半透明底板效果，Tab 标题加粗、清晰指示当前选中态，预留图标接入空间。

### R3. 开屏极速捕获弹窗 (Quick Capture Modal / Sheet)
- **行为**：进入网页或打开 App 时，自动唤起轻量优雅的快速捕获弹窗。
- **体验**：
  - 自动聚焦输入框，占位符文案自然友好（如「有什么想记下的？…」）。
  - 按回车立即保存入收件箱；支持连记或保存后自动淡出。
  - 支持轻触外部遮罩、按 `ESC` 键或右上角「完成/稍后再记」无感关闭。
  - 在收件箱页面可随时通过顶部栏或悬浮按钮再次唤出。

### R4. 按钮系统与组件层级优化
- **核心行动按钮 (Primary CTA)**：
  - 【现在】执行屏的 `[开始专注]` 升级为醒目的大号主要按钮（主色填充、加高 48~50pt、微圆角、文案带专注动感）。
- **次级与工具操作 (Secondary / Ghost)**：
  - `[换一个]` 与 `[稍后]` 从主按钮行分离，以次要胶囊/轻量圆角按钮排布，明确视觉主次，杜绝误触。
- **场景与时间选择器**：
  - 简化厚重的输入卡片，改用 iOS 风格的横向胶囊切换器（Pill Chips），视觉更轻灵。
- **触控与呼吸感**：列表项与各功能模块之间增加边距（gap-3 / gap-4），触控区域严格达到 44pt+。

### R5. 四个主要 Tab 界面的视觉升级
- **收件箱 (Inbox)**：大标题 (Large Title) + 优雅分组条目 + 快速记录栏与流畅卡片。
- **现在 (Now)**：以任务为绝对中心的单卡片聚焦视图，决策理由 (Why this?) 采用精致浅底小标签，底部主行动清晰开阔。
- **项目 (Projects)**：iOS Inset Grouped 风格列表，圆点状态指示灯取代粗糙厚标签，层级分明。
- **回顾 (Review)**：沉浸式卡片入口，清晰的历史时间线列表。

## Acceptance Criteria

- [ ] **AC1 色彩与层级**：全应用切换为 iOS 浅灰 Grouped 底色与纯白 Inset 卡片，深色模式纯黑底色，卡片去掉粗硬边框，视觉轻盈现代。
- [ ] **AC2 Tab 顺序**：Tab 栏首项为「收件箱」，其后为「现在」、「项目」、「回顾」。
- [ ] **AC3 开屏捕获**：打开应用/网页时，弹出极速捕获弹窗并聚焦输入框；输入文本按回车 → 成功存入收件箱，支持无缝关闭。
- [ ] **AC4 按钮与间距**：【现在】界面的 `[开始]` 具有统治性视觉权重，`[换一个]` 与 `[稍后]` 间距合理、不再拥挤；所有可点击控件热区 $\ge 44\text{pt}$。
- [ ] **AC5 功能与测试不回归**：所有既有业务逻辑（明晰向导、专注计时器、项目详情、日/周回顾）功能完整可用，单测全绿，构建无报错。
